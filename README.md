## GitHub Pages 部署

把以下 5 個檔案直接放到 repository 根目錄（最外層），不要再包一層資料夾：

```text
index.html
styles.css
app.js
data.js
README.md
```

然後到 **Settings → Pages → Build and deployment**：

1. Source 選 `Deploy from a branch`。
2. Branch 選 `main`。
3. Folder 選 `/(root)`。
4. 按 Save，並到 Actions 確認部署成功。

若更新既有網站，只需以本專案的 `data.js`、`app.js`、`index.html`、`styles.css` 替換原檔（若要完整更新功能，建議四個一起替換），再 commit changes。不要只覆蓋 `data.js`，若你原本的 `app.js` 與這份資料格式不同，可能會出現不相容。

## 測驗功能說明

- 每回合 3 題，必須全數作答後才會統一顯示答案與詳解。
- 「依題號順序」會先依原題號排列 107 道原題，再列 44 道期中風格題，最後列原先 42 道基礎題。
- 難度包含「基礎」、「進階」與「期中考應用」。
- 題目詳解可跳至對應的中文學習模組；分類統計只計算已批改的作答，未作答分類會顯示尚無資料。
- 作答紀錄存於目前瀏覽器的 `localStorage`；清除瀏覽器網站資料或改用另一台裝置不會自動同步。使用「匯出我的學習紀錄」可另存 JSON。

## 內容來源與使用邊界

課程觀念以提供的以下教材為基礎：

- `ChE_01_Intro_Syllabus_20260908.pdf`
- `ChE_02_IC_Industry_20260922.pdf`
- `ChE_03_ChE_Industry_20260929.pdf`
- `ChE_04_EMB_Thermo_20261013.pdf`
- `2026_Midterm_SampleProblems.pdf`

學習區中的整理、延伸公式與新增練習題是為了協助複習而編寫的教學性歸納。個別題目的原始敘述、標準答案與課堂簡化定義可能依課程講授口徑有所不同；尤其氫氣顏色分類、理想化熱機模型及車輛能耗的系統邊界，作答時請以授課內容及題目指定假設為準。
